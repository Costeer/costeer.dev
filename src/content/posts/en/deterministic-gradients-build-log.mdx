A deterministic visual system starts with a boring promise: the same input should produce the same output. Randomness can make a listing feel alive, but true randomness on every render makes screenshots, testing, and recognition harder than they need to be.

The post slug is a good seed because it is stable, human-readable, and already part of the publishing model. Hash it once, map small slices of the hash into bounded ranges, and pass the result to CSS custom properties. The design gets variation without giving up repeatability.

The important constraint is range. A gradient angle can move a little; it should not spin into spectacle. A fade stop can drift; it should not bury the title. A radial wash can move; it should not become a blob that demands interpretation.

This is the difference between a theme and a system. A theme says every technical post is blue. A system says technical posts share a blue vocabulary, then allows small differences that preserve scanning rhythm across a real home page.
